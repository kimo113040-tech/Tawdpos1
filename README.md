# نظام طود (Tawd) - إدارة المطاعم والمتاجر

**طود** هو نظام ويب متكامل لإدارة المطاعم والمتاجر، يشمل الكاشير، المخزون، الطلبات، الشيفتات، العملاء، والموردين، مع واجهات منفصلة للمصمم، المحل، السائق، والعميل.

## المميزات الرئيسية

- كاشير متكامل مع دعم الباركود.
- إدارة المنتجات والمخزون والمكونات.
- نظام الريسبي لحساب التكلفة.
- إدارة الشيفتات والموظفين والمرتبات.
- نظام طلبات للعملاء مع تتبع الطلب.
- لوحة تحكم للمصمم لإدارة المحلات والسائقين.
- واجهة عربية بالكامل مع دعم RTL.
- وضع ليلي/نهاري.

## متطلبات التشغيل

- خادم ويب يدعم PHP (مثل Apache أو Nginx).
- قاعدة بيانات MySQL.
- PHP 7.4 أو أحدث.
- متصفح حديث.
